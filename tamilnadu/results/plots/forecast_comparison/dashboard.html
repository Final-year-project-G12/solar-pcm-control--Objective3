Objective 3 — does the controller advantage survive a realistic weather forecast?

Tamil Nadu PCM-SWH, locked test years 2011–2015. Three forecast conditions compared: no forecast field at all (obs_version="V1"), the same 15-dim shape with the forecast zeroed (obs_version="V3", forecast_mode="none" — the ablation floor), and a realistic 1–3h GHI forecast (obs_version="V3", forecast_mode="smart" — smart persistence on the clear-sky index, not a perfect look-ahead). See CORRECTIONS_OBJECTIVE3.md §O3-5–O3-6 for the full method and tests.

Caveat on the DQN row (regime 0), resolved by a controlled check: the chart’s DQN bars compare “no forecast” to “realistic forecast” — not a controlled, same-seed ablation. DQN has substantially higher training variance in this project than SAC, so a same-seed, same-obs-shape check (obs_version="V3", forecast_mode="perfect" instead of "smart") was run to isolate the forecast effect. Result: that same seed, given a strictly better (perfect) forecast than the original no-forecast run, only reaches 28.3% shield cut — not 62%. So most of the originally-reported 62%→18.3% gap is retrain variance, and the true, isolated forecast-realism effect is 28.3%→18.3% (10 points) — real, but far smaller than first appeared. SAC is not subject to this caveat: all four SAC rows use the same framing and SAC has low retrain variance in this project, so its near-unchanged shield reduction is good evidence the result is real.

Sensor-fault re-evaluation

The original V1 checkpoint showed a severe ~99.5% delivery collapse for SAC regime 1 under a dead/stuck pyranometer (CORRECTIONS_OBJECTIVE3.md §O3-4). Re-running the sensor-fault suite on the newer V3 checkpoints (none/smart) does not reproduce this — both show mild degradation (1.2%–13.2%), in the same range as regimes 0 and 2. This suggests the severe regime-1 vulnerability was specific to that one training run, not an inherent property of “SAC on regime 1,” though per-checkpoint sensor-fault testing before deployment remains necessary either way. Zero hard-safety violations in every cell (shield acts on true state regardless of what the policy observes).
